REQUEST A BOOK

The CUSTECH University Library provides a book request service for students, lecturers and researchers who need academic materials that are not currently available in the library collection.

If you cannot find a required book or other learning material in the library, you can submit a request by providing the necessary information about the resource. The library staff will review the request and determine the appropriate action based on availability and library resources.

Please provide accurate information about the requested book, including the title, author, edition and other relevant details. This will help the library identify the required resource more easily.
